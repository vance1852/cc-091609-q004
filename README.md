# 野生药材采集监管

自然保护地可持续采集监管系统：管理资源调查版本、地块/核心区边界、团队与纸质
许可的审批冻结、断网巡护事件的签收归位、越界与超限隔离、勘误与申诉（职责分离），
并能按一次巡护完整还原许可余额、越界理由、申诉结果与每次状态变化。

`domain/contracts.py` 定义许可、限额和采集事件的对外数据形状；`fixtures/` 保存
一次脱敏的断网巡护导出（`harvest_patrol.json`）与对应的注册表种子
（`registry_seed.json`）。运行 `python -m compileall domain` 可在 Python 3.11
下检查契约。

## 架构

台账采用**仅追加事件溯源**（`wildharvest/ledger.py`）：

- 所有变化写成不可变日志条目（JSONL，带 SHA-256 哈希链）：版本发布、许可审批、
  事件签收、`pending → counted/quarantined` 状态转换、勘误、申诉。
- 当前状态是日志的纯函数折叠（`Projection`）；`Ledger.replay(verify=True)`
  从日志独立重算全部裁定并与日志中的状态转换链核对，篡改任一条都会暴露。
- 空间判定见 `wildharvest/geo.py`（纯标准库）：以设备精度为缓冲半径，精度圆
  **整体**落入许可地块且**整体**位于核心保护区外才合规；`within / outside /
  buffer_crosses`（核心区为 `clear / inside / buffer_crosses`）。证据保留
  定位原值、设备精度、到边界最近距离与投影说明。
- 限额按 **captured_at 采集时间归位**（同刻按设备序号），与联网到达顺序无关；
  在许可、团队年度、地块-物种年度、物种年度四个维度先占先得，超限或越界记录
  进入隔离，不占用后续额度，也不计入合法收获。

## 业务规则

1. **审批冻结**：许可审批时拷贝当时的资源调查条目与地块/核心区边界快照；
   版本一经发布不可覆盖，后续新版不影响已批许可。重叠地块的申报在发布边界层时
   写入 `parcel-overlap-warning`，不阻断合法利用。
2. **离线签发与去重**：事件按 `(设备, 序号)` 幂等签收；完全相同的重复上报记
   `duplicate-suppressed`，同序号不同内容抛 `DuplicateSequence`（疑似伪造）。
3. **隔离**：许可不存在/已暂停、不在有效期内、地块外、精度缓冲跨界、进入核心
   区（含缓冲触及）、或许可/团队/地块-物种/物种年度任一限额不足，一律隔离。
4. **暂停**：无任何采集记录的许可可暂停；已有记录只能追加勘误，不能暂停。
5. **勘误**：仅允许修正定位与重量字段，原值与每次修正（操作人、原因、时间）
   完整保留；勘误后全量重算，状态与越界理由的变化追加新转换记录。
6. **申诉**：仅隔离记录可申诉；裁定人不得是申诉发起人，也不得是该许可的审批人。
   撤销隔离必须通过新证据勘误或逐条豁免违规原因，使重算结果真正转为 counted。
7. **还原**：一次巡护的报告含每张许可的冻结版本、已采/剩余额度（含团队年度
   余额）、每条事件的原点/判定点、违规详情与证据、勘误链、申诉结果和完整
   状态变化链。

## 运行

```bash
python3 -m wildharvest.seedrun        # 装配种子+断网巡护，落盘 build/ 并输出报告
python3 -m unittest discover -s tests # 25 项规则测试
python3 -m compileall domain wildharvest tests
```

`python3 -m wildharvest.seedrun` 按设备 `received_at`（恢复联网后的到达顺序）
录入事件，由台账按采集时间归位核算；种子中的 seq18 雨后漂移点先隔离、经第二名
复核人凭差分 GPS 新证据撤销，seq20 因此从 counted 重算为 quarantined（许可
45kg 恰好占满）——这正是"到达乱序但归位确定、后续证据改变额度归属"的校验。
